
## This might be a good description of a customer we might prefer. Instead of "Legacy" they are called "Traditionals" bellow. 

```
When traditional organizations want to learn from high-velocity ones, they tend to look for magic ingredients, be it a six-pager, a specific leadership principle, or free lunches and Legos.

They usually ignore their own most obvious #dysfunctions, for example:
- Modern orgs see others' expertise as an asset to leverage and create success for the company. Traditional orgs do the opposite to protect their turf. Add external parties into the mix, and the problem multiplies.
- Modern orgs prefer challenging assumptions to find blind spots. Traditional orgs defend their existing proposals to save face.
- Modern orgs see coordination as a necessary evil that should be automated away as much as possible. Traditionals spend all day aligning, meeting, syncing, catching-up. 
- Modern orgs see change as opportunity. Traditionals see threat.

There usually is no magic ingredient missing that can put your org into overdrive. Rather, it's the baggage that weighs you down, which you don't see (or prefer not to).
```
